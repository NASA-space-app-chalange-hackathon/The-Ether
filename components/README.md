# components

React components grouped by feature:

- `ui/` — shared primitives (shell, nav, badges, status ring, cards)
- `body/` — interactive SVG body map and region side panel
- `charts/` — Recharts wrappers (trend lines with baseline bands, event annotations)
- `check/` — Daily Check steps (camera rPPG, PVT-lite, manual vitals, sleep, mood)
- `alerts/` — Action Center cards and the "Message to Ground" composer
